## 在新机器恢复数据

使用仓库的 ops/download_experiment.py，参数 --manifest experiments/boxing-lightweight-s3710-20260921/archive.json 和 --destination 所选下载目录。
然后使用 ops/restore_experiment.py，指定下载得到的 boxing-lightweight-s3710-100k-c2a8106.tar.gz、--sha256 9ee2daccf91c197b178d6ba7fc557177055ff296a542ce05c1df8450323f58df 和 --destination 一个新的空目录。成功生成 RESTORE-VERIFIED.json。
恢复只需要 Python 标准库，不安装依赖、不启动训练。运行环境安装参考 ops/install_restored_env.sh，但需另行授权；本归档环境含当前实例的版本记录与 SM120 编译包。没有在第二台新 GPU 上重建环境，本次验证范围是文件下载和恢复。
