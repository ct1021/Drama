## 轻量配置与短时张量计时

仅在内存中将编解码器 Mults 从 `[1,2,4,8]` 改为 `[1,2,3,4,4]`，保持深度16、
时序宽度512、Mamba两层、d_state16等其他设置；动作数18。未改远端配置文件。

| 项目 | 原公开配置 | 五层轻量候选底座 |
|---|---:|---:|
| 世界模型参数 | 21,925,667 | 7,161,603 |
| Actor/critic参数合计 | 3,419,664 | 3,419,664 |
| 序列模型参数 | 3,743,648 | 3,743,648 |
| 每批次行递归缓存（float32） | 164,864字节 | 164,864字节 |
| 世界模型前向+反向中位时间，16×128 | 107.97ms | 99.90ms |
| 想象中位时间，1024×16、上下文8 | 39.09ms | 39.54ms |

前向反向计时预热3次、记录10次；想象预热2次、记录6次。参数版本检查未变，
没有optimizer.step、actor反向、真实环境交互、正式训练或检查点写入。
预测部分包含原生损失的计算与反向，但不更新参数；随机张量不构成RL证据。
构造临时模型后的归一化缓冲会变化，不影响磁盘上的已有权重。

本批组件计时之和约缩短5.18%，不能当作端到端提速结论。参数减少67.34%，但想象规模、
序列主干和策略没有减少；不按7M/22M比例缩短训练预算。
五层编解码器与论文附录A.4.1设置对齐，但当前Mamba-2实际head_dim为64，论文表6为128；
本配置暂称轻量公共代码配置，不称逐项精确论文复现。[论文](https://arxiv.org/html/2410.08893v4)

## 时间预算

旧完整100K含评测为5.158小时；新实例CPU配额从原25核降为16核，候选结构尚未实现。
先按A/B/C每次5–6小时、D候选5–7小时估计：四组各一个种子共20–25 GPU小时，
另留2–3小时校准和排错，合计22–28小时。是规划区间，不是已测完整运行时间或费用授权。
候选实际配置通过验收后，仍需用端到端短校准更新预算。

文件：`inventory.json`、`probe.json`、`verify.json`、`profile-timing.json`。
`measure_profiles.py` 是本次通过SSH标准输入执行的原始资源计时脚本，固定指向已验证的
远端代码目录；不属于模型实现或正式训练入口。
