# H1-R1 实现与验收

新增 profile：`lightweight-readout`（C，仅预测头分工）和 `lightweight-routed`（D，持续递归路由）。
`public` 与 `lightweight` 的配置选择保持不变。结构转换在世界模型构造、优化器创建之前完成。

## 接入范围

`sub_models/task_routing.py` 为 D 分块保存输入/输出投影允许连接的参数；B/C 只读共享区，
SSM 与卷积缓存维度不变。门控、dt、层前归一化、层后归一化及最终归一化都遵循区间边界。
底层 scan 和 selective update 继续使用现有 GPU 实现；由于原组合内核的归一化分组不匹配，
D 禁用组合 scan/norm 和 fused add-norm，改用分区归一化。CUDA Graph 想象仍启用。

C/D 使用同样的 `RestrictedReadout` 包装实际预测模块，因此训练、想象以及真实决策的先验调用
均应用限制，不依赖某一个调用点手工遮挡。策略读取总维度不变。允许块和预测头保留同种子原始初始化的
对应权重，转换不消耗额外随机数。禁止的连接没有注册自由参数，但线性投影仍物化成稠密矩阵计算；
不能声称获得稀疏算子的加速。

## 性能与公平性尚需谨慎

组件计时的世界模型前后向 A/C/D 约100.3/112.0/123.5ms，想象约38.1/38.3/41.8ms。
前后向测量包含逐参数有限值同步检查，D注册参数张量更多，因此不能把该比例直接当训练速度开销。
主计时采用 `run_task_routing_integration.py` 的三组1800步真实短训练，在1200–1700步统计相同指标时间戳，
排除初始预热与终点评测。完整100K与终点性能仍未由这些检查证明。

D和C并非等参数，首轮只能筛选设计；稀疏化/容量变化仍是替代解释，后续有效容量匹配对照不可省略。
原定门槛：D实测完整更新时间相对A增加不超过15%、缓存不增加、无工程异常，再考虑正式对照。
不能通过改变门槛、缩短100K预算或引用短测试得分让结果“通过”。
